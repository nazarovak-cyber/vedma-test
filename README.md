# Тест «Какая скрытая сила живёт в вас?»

Воронка для Instagram по книге Виктории Байн «Я ведьма»: оффер → тест из 10 вопросов → личный расклад (архетип, уровень раскрытия, тень, практики) → книга за 290 ₽.

Один файл `index.html`, без зависимостей. Цена, ссылка на оплату и ID Яндекс.Метрики настраиваются в начале скрипта (`PRICE`, `checkoutUrl`, `YM_ID`).
